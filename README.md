# Spatial analysis portfolio

GIS and remote sensing projects by Oladipupo Elegbede, MSc GIS and Remote Sensing, University of Aberdeen.

## Projects

| Project | Tools | Summary |
|-|-|-|
| [Northern Nigeria vulnerability model](northern-nigeria-vulnerability-model/) | ArcGIS Pro, ArcPy, Spatial Analyst | MSc dissertation. AHP weighted multicriteria model of environmental vulnerability to insurgency across 13 states at 100 m, tested under five weighting scenarios and validated against ACLED and UCDP GED |
| [Nigeria drought dashboard](nigeria-drought-dashboard/) | R, terra, sf, exactextractr, Shiny, Leaflet | SPI-12 and SPEI-12 drought monitoring for Nigeria, 1981 to 2024, with Theory of Runs event analysis aggregated to 37 states and 146 river catchments |
| [Newburgh wildfire risk](newburgh-wildfire-risk/) | ArcGIS Pro, ArcPy, UK open data | Weighted overlay wildfire risk assessment for a coastal Aberdeenshire village beside the Forvie NNR, using UKCEH Land Cover, OS Terrain 50 and OS OpenMap Local, tested under three weighting schemes |
